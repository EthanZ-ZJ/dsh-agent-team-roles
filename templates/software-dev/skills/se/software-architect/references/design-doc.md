# 设计文档骨架（L2+）

> 用途：L2 及以上方案的可评审文档；给 Lead 拍板、给 DEV 实现、给 CR 核对、给 TSE 派生用例。
> 方法来源：Google 设计文档结构裁剪 + arc42 按需取节。离线可复制。

## 一、先判断：写不写

**写**：跨 ≥2 模块；新外部依赖；新表/新事件/新权限点；改变 TSE 验收方式；需要跨角色对齐。

**不写**：实现手册（照代码能写出来）；没有备选与权衡；原型阶段；L0/L1。文档只该写「代码里看不出来的信息和理由」。

## 二、骨架（复制后删掉不需要的节，但不许留空节）

```markdown
# <方案名称>

- 作者：SE
- 日期：YYYY-MM-DD
- 档位：L2 | L3
- 状态：草案 | 待评审 | 已确认
- 关联：ASR 编号 / ADR 编号 / 契约权威路径

## 1. Context & scope

现状一段话 + 本次改动范围。引用现状图（§3 测绘产出）。
读者能在 5 分钟内知道「现在是什么样、这次改哪里」。

## 2. Goals

可验证的目标，3–5 条。每条能映射到 ASR 或验收标准。

## 3. Non-goals

≥3 条，每条写「为什么这次不做」。
例：不做多租户隔离（原因：当前只有单租户客户，引入会改 3 个核心表）。

## 4. Design

### 4.1 总览
目标态容器图 / 模块图 + 一句话说明每个新部件。

### 4.2 数据
数据所有权表（谁写、谁读）；新表/字段；一致性选择与冲突规则；迁移与回滚。
（数据细节放契约/迁移文档，这里给决策与路径。）

### 4.3 接口与契约
新增/修改的契约列表 + 权威路径；版本与兼容策略；失败语义。
（字段细节不重复，引用契约文件。）

### 4.4 失败与降级
依赖故障、超时、分区、重复投递、部分失败时的表现与恢复路径。

### 4.5 安全与权限
认证/授权点、数据边界、审计、敏感数据处理。

### 4.6 运维
部署方式、监控指标、告警阈值、回滚步骤、容量假设。

## 5. Alternatives considered（核心节）

至少 2 个备选 + 维持现状。每个写：做法、优点、缺点、放弃原因。
结论引用 trade-off 矩阵与 ADR 编号。

## 6. Cross-cutting concerns

日志、指标、追踪、配置、feature flag、灰度、数据保留、合规。

## 7. Risks

风险 / 概率 / 影响 / 缓解 / 触发信号 / 负责人。
不允许「暂无」；未识别写「证据不足 + 需要什么信息」。

## 8. Open questions

问题 / 需要谁回答 / 截止时间 / 不回答的后果。
未决问题必须出现在给 Lead 的汇报里，不能只写文档里。

## 9. 交接与验证点

- 交 DEV：按契约边界拆的任务（顺序 + 依赖 + 禁止事项）。
- 交 TSE：ASR 场景表、边界/失败用例、fitness function 候选。
- 交 CR：契约条目 ↔ diff 对照点。
```

## 三、每节的最低要求

| 节 | 最低要求 | 不合格信号 |
|---|---|---|
| Context & scope | 一段话 + 一张现状图引用 | 从技术选型开始写，不交代现状 |
| Goals | 可验证，3–5 条 | 「提升用户体验」 |
| Non-goals | ≥3 条带原因 | 没有这一节，或只有「暂不考虑」 |
| Design | 目标态图 + 数据 + 失败 + 安全 + 运维 | 只有模块清单，没有失败与运维 |
| Alternatives | ≥2 真备选 + 维持现状 + 放弃原因 | 只写选中方案 |
| Cross-cutting | 至少日志/指标/配置/灰度 | 全缺 |
| Risks | 每条带触发信号与负责人 | 「暂无风险」 |
| Open questions | 每条带决策人与截止 | 没有未决问题（通常等于没审） |
| 交接 | 三份清单齐全 | 一句「按文档实现」 |

## 四、长度与删减

- L2：3–10 页。超过 10 页先删「删了不影响决策」的内容（背景科普、技术教程、完整 schema、大段代码）。
- 大项目可到 10–20 页，但要先确认读者真的需要。
- 图：现状图 + 目标图 + 1–2 张关键时序（仅当时序决定正确性）。每张图标注它回答的问题。
- 不贴完整 schema/代码：给权威路径 + 只贴决策相关片段。

## 五、评审前自检

- [ ] Goals 每条可验证？
- [ ] Non-goals ≥3 条且带原因？
- [ ] Alternatives 有 ≥2 个真备选与放弃原因？
- [ ] 数据所有权、一致性、迁移回滚写了吗？
- [ ] 失败模式与降级写了吗？
- [ ] 风险有触发信号？未决问题有决策人与截止？
- [ ] 交接三份清单齐全？
- [ ] 与 ADR/契约冲突或重复吗？重复部分改成引用。

# 架构与契约

适用于跨模块、公共 API/事件/配置、数据所有权或难回退的变更。模块内局部实现且不改变契约时，指出现有约定即可，不必新建 ADR。

1. **先核实，再画边界。** 读现有架构图、ADR、权威类型/Schema、生产者和消费者。用路径或符号区分事实、假设、待确认项。跨系统时画上下文图；跨应用、服务或数据存储时再补容器图。标明调用方向、持久状态和负责人，不必画类图。
2. **比较可行方案。** 给出推荐方案及最小变更或维持现状的备选，解释被排除的原因。只比较与本任务有关的约束，如兼容性、一致性、故障恢复、部署顺序、维护成本。给出能改变推荐结论的条件；没有证据的数字标为待验证。
3. **把约定写成可测契约。** 标明唯一权威文件、生产者和消费者。写清输入/输出与字段约束、默认值、错误语义及版本策略；涉及重试、重复提交或乱序时，说明幂等、时序和失败处理。附一个正常例和一个边界或失败例，让 TSE 能据此编写验收用例。避免在多处复制枚举、错误码或字段定义。
4. **有迁移就明确兼容窗口。** 写出旧客户端与新服务、新客户端与旧服务的兼容性、发布与回滚顺序、停止迁移的观测信号；无回滚时明确恢复路径及风险。
5. **让 Lead 做决定。** 先交草案：问题、范围、推荐与备选、契约位置、受影响的消费者、验收点和未决事项。关键结构或难回退的决策用 ADR 记录背景、备选、决定、取舍、状态；旧决策被替代时从新记录链接旧记录。Lead 确认后才落盘契约；只写角色允许的文档与接口/类型定义，不改业务实现，不代跑测试。

## 选图与划界

- **系统上下文图**：把目标系统画成一个整体。列出使用者、外部系统，以及它们为什么交互。标出谁发起调用、谁拥有数据、哪些依赖不受本团队控制。用来回答「改动会影响谁」。
- **容器图**：只展开目标系统中的可运行单元和数据存储，例如客户端、服务、后台任务和数据库。容器不是特指 Docker。每项标注职责及所有者，每条箭头标出方向、目的、同步或异步以及协议或事件名。用来回答「该由谁实现，故障会传到哪里」。
- 现状和提案分开标注。变化只涉及一条调用链时，优先给局部图或关系表，连同受影响的下游及路径，不重画整个系统。只有当时序决定正确性时才补时序图，覆盖失败、重试或迟到消息。仓库已有格式优先。

## 契约草案模板

1. **范围与证据**：问题、非目标、当前行为及出处；列出假设、待确认项和负责人。
2. **边界与权威**：生产者、消费者、数据所有者、接口或 Schema 的唯一权威位置；标出谁能写、谁只能读。
3. **行为**：输入/输出、必填与可选、缺失与空值、默认值、不变量和校验位置；列出错误、调用方可否重试及重试后的语义。异步接口另写重复、乱序和超时如何处理；权限与数据边界相关时写明检查责任。
4. **兼容与发布**：列出旧消费者→新生产者、新消费者→旧生产者分别怎样运行、何时才允许停止兼容。需要迁移时说明先扩展、再迁移验证、最后收缩是否可行；定义停止信号、回滚边界及不可逆之后的恢复方案。
5. **验收**：至少一个正常例和一个失败例，均给出前置条件、操作、可观察结果以及预期副作用。若变更跨版本，再给混合版本用例。把尚不能验证的条件及所需证据单列。

### 示例：队列事件增加可选字段

假设生产者要在 `TaskQueued` 中新增 `priority`。约定权威 Schema 定义缺失等同 `normal`，显式 `null` 与未知值非法；消费者不应在未确认旧版本能忽略未知字段前启用发送。消费者先支持旧消息和新字段，生产者再开启发送。验收包括：旧消息仍按 `normal` 入队；`null` 进入既有无效消息处理流程且不创建任务；相同事件 ID 重投不会重复创建任务。若无效消息率超过约定阈值，先关闭生产者发送新字段，再核实积压中的新消息是否仍可消费；不能仅靠回滚旧消费者来消除已发出的消息。

## ADR：什么时候写、怎么写

影响跨模块边界、长期兼容、关键质量目标或回滚难度的选择值得单独写 ADR；实现细节记在设计或契约里即可。一个 ADR 记录一个决定，不拿它替代接口契约。

- **标题 / 状态**：一句话写明选择，状态用「提议」「已接受」「已被替代」。
- **背景与约束**：为何现在要决定，哪些需求、证据和不确定性影响选择。
- **备选**：记录可行方案（包括适用时的维持现状）；对照同一组约束写出利弊与放弃原因。
- **决定与后果**：写清选什么、为何现在选、接受了哪些代价和风险；列出受影响方、后续工作和何时重评。把接口细节放在契约里，ADR 引用仓库内的权威位置。
- **变更历史**：已接受的决定被推翻时，新增记录并建立替代关系，保留旧决定和当时的理由。

提交草案时，确保 Lead 能据此拍板、DEV 能找到唯一契约、TSE 能把验收点转为用例。所有方法与模板均在本技能内；不需要查阅外部资料。
